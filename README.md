# Синтез фазовой ДОЭ для четырёх плоскостей

Программа получает **четыре изображения 128×128**, совместно обрабатывает их нейросетью и формирует **одну фазовую ДОЭ 128×128**. Затем рассчитывает восстановленные изображения на четырёх расстояниях по формуле Френеля.

Основной запуск выполняется в Docker. Для него нужны Docker Desktop, четыре входных PNG и обученные веса `checkpoints/best.pt`.

## Параметры задачи

| Параметр | Значение |
|---|---:|
| Входные изображения | 4 × 128×128, grayscale |
| Выходная ДОЭ | 128×128, PNG, 8 бит, grayscale |
| Длина волны | 532 нм |
| Шаг пикселя ДОЭ | 10 мкм |
| Расстояния восстановления | 24,1; 25,3; 26,5; 27,7 мм |

Файлы должны называться `pic1.png`, `pic2.png`, `pic3.png`, `pic4.png`. Они соответствуют расстояниям в указанном порядке.

## Назначение файлов

- `main.py` — запускает нужный скрипт по команде: обучение, инференс, проверка изображений или классический алгоритм
- `model.py` — архитектура нейросети `PhaseDOEUNet` на основе U-Net; принимает четыре изображения и предсказывает фазу ДОЭ
- `train.py` — обучает нейросеть и сохраняет веса
- `mnist_dataset.py` — формирует обучающие наборы из четырёх изображений MNIST
- `dataset.py` — загружает и проверяет четыре входных изображения; при необходимости может подготовить примеры MNIST
- `infer.py` — загружает веса, создаёт ДОЭ и рассчитывает четыре восстановленных изображения
- `propagation.py` — рассчитывает распространение Френеля в PyTorch
- `GS.py` — классический многоплоскостной алгоритм Гершберга—Сакстона для сравнения с нейросетью
- `Dockerfile` и `requirements.txt` — сборка контейнера и список зависимостей

## Порядок запуска в Windows

Все команды ниже выполняются в **PowerShell из корневой папки проекта**.

### 1. Подготовить проект

Клонируйте репозиторий и перейдите в его папку:

```powershell
git clone https://github.com/EL-Rolan/Genii4.2.git
cd Genii4.2
```

Проверьте наличие обученных весов:

```powershell
Test-Path .\checkpoints\best.pt
```

Команда должна вернуть `True`. Если весов нет, сначала выполните обучение по шагу 2. Для сдачи файл `checkpoints/best.pt` должен быть добавлен в репозиторий.

### 2. Обучить модель (только если готовых весов нет)

Создайте виртуальное окружение и установите зависимости:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Запустите обучение:

```powershell
.\.venv\Scripts\python.exe main.py train --epochs 10 --batch-size 4 --output-dir checkpoints
```

`mnist_dataset.py` автоматически загрузит MNIST при первом запуске обучения. По завершении в `checkpoints` появятся `best.pt`, `last.pt` и `history.csv`. Для дальнейшего запуска нужен `best.pt`.

### 3. Подготовить тестовый комплект

Создайте папку `test_data\set_01` и положите в неё четыре PNG:

```text
test_data\
└── set_01\
    ├── pic1.png
    ├── pic2.png
    ├── pic3.png
    └── pic4.png
```

Каждое изображение должно быть размером 128×128 пикселей. Программа преобразует его в grayscale. Проверить комплект можно командой:

```powershell
.\.venv\Scripts\python.exe main.py check-images --data-dir .\test_data\set_01
```

### 4. Собрать Docker-образ

Убедитесь, что Docker Desktop запущен, затем выполните:

```powershell
docker build -t genii-doe .
```

При сборке Dockerfile проверяет наличие `checkpoints/best.pt`. Без этого файла образ не соберётся.

### 5. Запустить нейросеть на одном комплекте

```powershell
$inputPath = (Resolve-Path .\test_data\set_01).Path
$outputPath = (New-Item -ItemType Directory -Force .\output\set_01).FullName

docker run --rm `
  --mount "type=bind,source=$inputPath,target=/data/input,readonly" `
  --mount "type=bind,source=$outputPath,target=/data/output" `
  genii-doe
```

Контейнер запустит `infer.py`: четыре входных изображения будут обработаны одним вызовом модели, после чего программа сохранит одну ДОЭ и четыре восстановления.

### 6. Запустить на пяти и более комплектах

Создайте в `test_data` отдельную папку для каждого комплекта (`set_01`, `set_02` и т. д.). В каждой папке должны находиться свои `pic1.png`–`pic4.png`. Запустите все комплекты одной командой:

```powershell
Get-ChildItem .\test_data -Directory | ForEach-Object {
    $inputPath = $_.FullName
    $setName = $_.Name
    $outputPath = (New-Item -ItemType Directory -Force ".\output\$setName").FullName

    docker run --rm `
      --mount "type=bind,source=$inputPath,target=/data/input,readonly" `
      --mount "type=bind,source=$outputPath,target=/data/output" `
      genii-doe

    if ($LASTEXITCODE -ne 0) {
        throw "Ошибка обработки комплекта $setName"
    }
}
```

Результаты каждого комплекта сохраняются в отдельной папке `output\set_01`, `output\set_02` и т. д.

## Пример результатов работы программы

После обработки одного комплекта в папке `output\set_01` появятся:

```text
output\set_01\
├── doe.png                    # итоговая фазовая ДОЭ
├── doe_phase_radians.npy      # фаза в радианах до квантования
├── reconstructed_1.png       # восстановление на 24,1 мм
├── reconstructed_2.png       # восстановление на 25,3 мм
├── reconstructed_3.png       # восстановление на 26,5 мм
├── reconstructed_4.png       # восстановление на 27,7 мм
└── metrics.csv                # КК (Pearson) и ИСС (SSIM)
```

`doe.png` — выходная ДОЭ в формате PNG, 128×128, 8 бит, grayscale. Файлы `reconstructed_1.png`–`reconstructed_4.png` показывают результат распространения на соответствующих расстояниях.

В `metrics.csv` записываются отдельные значения для четырёх плоскостей. Пример структуры файла (числа здесь не приведены):

```csv
plane,distance_mm,output_pixel_pitch_um,pearson,ssim
1,24.1,...,...,...
2,25.3,...,...,...
3,26.5,...,...,...
4,27.7,...,...,...
```

Среднее значение КК и ИСС для комплекта рассчитывается как среднее четырёх значений соответствующего столбца. Автоматическая сводная таблица по всем комплектам не создаётся.

## Классический алгоритм Гершберга—Сакстона

`GS.py` реализует альтернативный способ синтеза ДОЭ без нейросети. Алгоритм начинает со случайной фазовой карты и выполняет 400 итераций. На каждой итерации поле распространяется на четыре плоскости; в каждой плоскости амплитуда заменяется заданной амплитудой входного изображения при сохранении текущей фазы. Затем поля распространяются обратно к ДОЭ, объединяются, и по их средней фазе обновляется фазовая карта.

Для запуска подготовьте четыре файла `pic1.png`–`pic4.png` **в корневой папке проекта рядом с `GS.py`**, затем выполните:

```powershell
.\.venv\Scripts\python.exe main.py classical
```
